Configuración

Respaldo automático en GitHub

Funciona sin internet: las reservas se guardan en el teléfono y se suben solas cuando hay conexión. Usa un repositorio privado y un token “fine-grained” con acceso solo a ese repositorio (permiso Contents: Read and write). El token se queda en este aparato y solo se envía a GitHub.

Respaldo en archivo

Guardar o restaurar un archivo

Crea un archivo con todas las reservas para guardarlo en Archivos o iCloud, o para pasarlo a otro teléfono. Al restaurar se agregan las reservas que falten; las que ya tienes se conservan.
